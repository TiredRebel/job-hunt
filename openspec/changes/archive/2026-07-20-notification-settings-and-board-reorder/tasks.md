# Tasks — notification settings + board card reordering

Scoped for implementation by **Sonnet 5**. Groups are dependency-ordered:
schema → gateway → generated client → web → n8n → docs. Each group ends
with a verification step and must leave every existing gate green before
the next group starts.

Gate commands (from each app dir): `apps/api` and `apps/web` —
`npm run typecheck && npm run lint && npm run test && npm run build`.
Coverage thresholds are enforced (Phase 7); new service/guard code in
`apps/api` and new `src/lib/**` code in `apps/web` needs tests or the gate
fails.

Design references (`design.md`): **D1** env-var-referenced secrets, **D2**
typed singleton table, **D3** integer positions rewritten in full, **D4**
`sortBy=board` allowlist entry, **D5** advisory `stage` column, **D6** n8n
fetches settings, **D7** computed env-presence field, **D8** dnd-kit
sortable migration.
